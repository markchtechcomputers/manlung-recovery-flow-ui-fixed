Selfie Request Generator

Create an authorized HTTPS selfie request link tied to an existing case.

Your secure selfie link will appear here.
Waiting

How it works

Admin generates a short-lived request. The recipient opens the HTTPS link, explicitly grants camera permission, sees a 3 → 2 → 1 countdown, and one selfie is captured and uploaded to the linked case.

Authorized use only.
Camera access is never started secretly. The recipient must explicitly allow the browser camera permission.
Evidence is stored in the existing private recovery-evidence storage and appears in the existing Evidence Review/case workspace.
