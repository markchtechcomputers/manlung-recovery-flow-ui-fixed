Install Manlung Recovery

Add Manlung Recovery to your device's home screen for quick access to case tracking and recovery support. This installs the website as an app—there is no APK download.

Preparing the install option…

If the install button is unavailable

  1. Android (Chrome): open the browser menu (⋮), then choose Install app or Add to Home screen.
  2. iPhone/iPad (Safari): tap Share, then Add to Home Screen.
  3. Desktop: use the install icon in the address bar or choose Install Manlung Recovery from the browser menu.
